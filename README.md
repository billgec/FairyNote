# FairyNote
Open Source iOS Notes App, made for studying.

Handschriftliche Notizen auf dem iPad mit Apple Pencil (PencilKit), Notizbücher, Papiervorlagen und später PDF-Annotation, Suche und iCloud-Sync.

- Plan & Roadmap: [docs/PLAN.md](docs/PLAN.md)
- Bauen: `FairyNote.xcodeproj` mit Xcode 16+ öffnen, iPad-Simulator oder eigenes iPad wählen, Run.
